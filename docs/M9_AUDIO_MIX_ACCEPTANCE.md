# M9 全流程混音与母带安全验收

> 版本：`0.22.14`
> 自动化状态：`DONE`
> 真实音频设备听感：`BLOCKED`（等待桌面扬声器/耳机与外部玩家）

## 目标

既有六总线已经覆盖海浪、天气、工具、结构、钓鱼、生存、设备、岛礁、导航和生物事件，但所有总线曾直接汇入主增益；雷声、鲨鱼咬击、结构断裂和 UI 确认同时发生时没有统一峰值保护，决策声音也必须与持续环境/音乐争夺空间。本切片只调整混音底盘，不替换已有声音身份和玩法时序。

## 母带链

运行时拓扑为：

`ambience / effects / creatures / music -> underwater low-pass -> master gain`

`ui -> master gain`

`master gain -> dynamics compressor -> destination`

母带压缩器固定为 `threshold=-10 dB`、`knee=5 dB`、`ratio=12:1`、`attack=3 ms`、`release=200 ms`。它只保护总输出峰值，不抬高安静素材，也不把 UI 送入水下低通。

## 决策提示让位

| 等级 | 环境保留 | 音乐保留 | Attack / Hold / Release | 典型事件 |
| --- | ---: | ---: | --- | --- |
| `notice` | 86% | 68% | 25 / 200 / 280 ms | 普通鱼讯、信号抵达 |
| `warning` | 70% | 48% | 20 / 420 / 400 ms | 断钩/断线、呼吸与生存警报、鸟害、鲨鱼预兆、强鱼讯 |
| `critical` | 52% | 30% | 12 / 650 / 520 ms | 氧气/饥渴危险、鲨鱼蓄势、玩家被咬 |
| `failure` | 34% | 16% | 15 / 1100 / 1050 ms | 溺水、鲨鱼或生存失败 |

让位只作用于持续环境和音乐；效果、生态与 UI 提示总线保持原增益。调度直接写入 Web Audio 时间线，重叠事件先保持当前包络再重排 attack/hold/release；活动窗口内只有同级提示能延长、更高等级能抢占，普通鱼讯不能提前抬起鲨鱼/失败包络。整个过程不依赖页面定时器，因此切后台和固定步暂停不会把总线永久卡在低电平。

## 自动证据

- `src/game/audio/mix.test.ts` 锁定四档衰减严格递增、无定时器包络的精确恢复点，以及母带阈值/比率/attack/release 安全范围；
- `AudioSystem.test.ts` 继续证明音频图尚未启动时关键字幕仍发布，同时记录最后一个决策提示等级；
- `npm run test:audio-mix` 从真实页面手势启动 Chromium `AudioContext`，要求六总线、世界低通、主增益和压缩器同时就绪；失焦后 `focusMuted=true / masterTargetGain=0`，恢复后目标值回到 `0.78`，浏览器错误必须为零；
- `release:check` 对 `dist` 静态包重复上述浏览器门禁，并把完整状态写入 `artifacts/release/audio-mix-lifecycle.json` 和候选报告的 `audioMixLifecycle`。

## 边界

本机 Xvfb/Chromium 能证明 Web Audio 图建立、参数、状态迁移和自动播放手势闭环，但不能证明耳机频响、声像、真实响度、HRTF 外化感或多事件主观层次。以下仍必须在目标桌面设备完成：

- 1280x720/30 与 1920x1080/60 各连续游玩一轮，检查海浪、风暴、设备和音乐底层不会遮蔽鱼讯、氧气、鲨鱼蓄势与结构断裂；
- 耳机复核左右方位、远近衰减、水上/水下切换和 HRTF 打捞，不出现点击、泵音或明显削波；
- 无说明玩家确认字幕与声音强弱传达一致，静音/失焦/恢复不会漏掉关键状态。

本切片没有新增位图、PBR 派生、音频文件或第三方素材，Image 2 high 资产门禁未触发且没有被降低。
